# Manual test plan

Run against a **test bucket** (or a separate prefix in a throwaway bucket) and **test
vaults** only. Never point it at a vault or bucket you care about: the plugin only writes
under `_integrity/`, but LiveSync's own maintenance actions used below rewrite journals.

## Setup

1. Two test vaults, A and B (two Obsidian vault folders on the PC, or one PC vault and one
   phone vault). Install Self-hosted LiveSync in both, Object Storage mode, same bucket,
   prefix and passphrase, E2EE on. Let them sync a few notes and confirm they match.
2. Build the plugin (`npm run build`) and copy `build/main.js`, `build/manifest.json`,
   `build/styles.css` into `<vault>/.obsidian/plugins/t7-livesync-integrity/` in both
   vaults (or set `LIVESYNC_INTEGRITY_PLUGIN_PATH` in `.env` for one of them). Enable it.
3. In each vault's plugin settings, set a device name ("A", "B") and check that the
   "Connection" line shows the test bucket and prefix.

## After the tests

Delete `<prefix>_integrity/` from the test bucket if the bucket is reused for anything else.
